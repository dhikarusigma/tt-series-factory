# Фабрика коротких серий (Remotion + ElevenLabs + ffmpeg)

Этот скилл описывает, как мы с владельцем канала делали серии «Вебинар, который нельзя выключить» и «Солнечная буря». Его можно подставить под любой другой канал: поменяй героев, жанр и тексты, процесс останется тем же.

## 0. Что нужно на компьютере
- Claude Code (приложение, вкладка Code), Windows/Mac.
- Node.js 20+, Python 3.12+, ffmpeg в PATH.
- Проект Remotion (React). Минимум: `remotion`, `@remotion/cli`, `@remotion/renderer`. Для 3D: `three`, `@react-three/fiber`, `@remotion/three`.
- Подключения (по желанию): коннектор ElevenLabs (озвучка, поиск голосов), расширение Claude in Chrome (вход в сайты под твоим аккаунтом), Browser pane в приложении.
- Папка памяти Claude (`memory/`): сюда Claude пишет вкусы владельца и решения. Включи ему привычку записывать правки в память.

Структура, на которую опирается процесс (названия можно менять):
```
remotion_ebonit/
  src/series/        сцены (Sun1.tsx, Sun2.tsx), тайминги (sun1_tl.ts), риг (flat.tsx), looks.ts
  tools/stills.mjs   кадры для проверки:  node tools/stills.mjs <Comp> <outDir> 100,400,800 --scale=0.35
  tools/render.mjs   рендер:              node tools/render.mjs <Comp> final out/x.mp4   (сам подбирает CRF до 29 МБ)
  public/            музыка, логотип, sfx
series_C/            сценарии (.md), голос (voice/), музыка (mk_music_sun.py), микс
```

## 1. Порядок работы над серией
1. **Образец и аналитика.** Попроси у владельца 2–3 ролика-образца и скрины аналитики (удержание, просмотры по частям). Делай выводы по данным: что цепляет первые секунды, где провал.
2. **Сюжет.** Яркий странный или опасный образ в обычной обстановке плюс реальный сюжет. Обещание исхода в первые 3 секунды. Главы, «Правило N», таймер. Без баяна и без «уже было». Герои: 2–3 человека, а не шестеро.
3. **Сценарий.** Реплики короткие, по одной мысли. Хук: время + последствие («В 07:35 небо загорится, в 07:41 погаснет свет…»). Факты по безопасности сверяй с официальными источниками.
4. **Тайминг-файл** `sunN_tl.ts`: массив реплик, оценка длины `длина/13.5*24` кадров, словарь `REAL` для реальных длительностей, `SUN*_S` (старты), `SUN*_D` (длины), `SUN*_FRAMES`. Все сцены считаются от него.
5. **Сцены.** Разбей на сцены A–F по границам `SC`. На каждой: подробный фон, персонажи в обычной обстановке, плашки/правила, HUD-таймер, субтитры, звуки.
6. **Музыка** процедурная (numpy): дрон, тиканье, сердцебиение, нарастание к кульминации. Кульминация привязана к номеру реплики.
7. **Озвучка**, потом пересборка по реальным длительностям (раздел 3).
8. **Проверка**: контактный лист кадров, затем правки пачкой (раздел 4).
9. **Рендер** до 29 МБ, отправка владельцу, публикация (раздел 5).

## 2. Персонажи (flat-риг)
- Профильное тело, голова с эмоциями `emo`: `calm/talk/worry/shock/smile/angry/think`. Нейтральный рот прямой линией, борода и кепка задаются в `looks.ts` (`beard`, `bigBeard`, `cap`, `capBack`, `capColor`).
- Режимы тела: `stand`, `point`, `walk`. Не используй `sit`, персонаж «лежит на полу».
- Узнаваемость героя держится на 2–3 приметах (бандана, кепка козырьком назад, борода), а не на сложном лице.
- Не рисуй лицо анфас вместе с профильным телом; фронтальный вариант мы пробовали и откатили.
- Длинные волосы рисуй боковыми прядями, а не сплошным полотном за головой: иначе под подбородком получается «борода».

## 3. Озвучка (ElevenLabs)
- Бесплатный аккаунт: библиотечные голоса (например, Artspace) недоступны через API, только на сайте. Проверь `check_subscription`: лимит символов, сброс по дате. Платный тариф снимает оба ограничения.
- Через сайт: открыть Text to Speech, выбрать голос, вставить реплику, Generate. Каждую реплику отдельным файлом. Скачивание файлов делай только после разрешения владельца.
- **Эмоции** (модель Eleven v4): теги в квадратных скобках перед фразой: `[calm, ominous]`, `[urgent]`, `[whispers]`, `[sighs]`; многоточие даёт паузу и вес; ЗАГЛАВНЫЕ дают ударение; тег можно составлять свободно, комбинируй два. Стабильность ниже (Creative) даёт больше эмоций. Скорость 0.7–1.2. В v4 нет тегов `<break>`.
- **Нормализация:** `silenceremove` по краям, `loudnorm I=-18`, моно 44.1 kHz. Реальная длительность каждой реплики в кадрах (`ceil(sec*24)`) идёт в `REAL`.
- Затем пересобери музыку (`python series_C/mk_music_sun.py <часть> <индекс_кульминации>`) и смикшируй голос поверх (ffmpeg, 2 прохода).

## 4. Проверка качества: как мы ловим баги
Владелец смотрит ролик глазами зрителя. Он придирается к одному и тому же. Проверяй сама:
- **Контактный лист.** `stills.mjs` на ключевых кадрах (шаг 100–120), затем склей в сетку и смотри. Проверяй каждую сцену.
- **Что ищем:** текст или плашка налезает на лица; титры больше 3 строк; предметы выходят за кадр; предметы висят в воздухе (столы и мониторы должны стоять на полу); пустой фон; одинаковые улыбающиеся лица без эмоций; «шарик-картинка» вместо анимации; подпись обрезана по краю.
- **Анимация.** Волны и вспышки идут из центра источника. Эффекты должны жить: шум, мерцание, пульс.
- **Правь пачкой.** Собери все замечания, поправь, перерендери один раз. После жалобы ищи такие же баги по всему ролику, а не только в названной сцене.
- **Измеряй, не гадай.** Сравнивай с эталонным кадром, не на глаз «вроде нормально».

## 5. Публикация и аналитика
- Смотри «Аналитика → Подписчики → Пики активности» (часы и дни). Выкладывай за 1–2 часа до пика, чтобы набрать первые просмотры. Для школьной аудитории обычно будни 15:30–16:30 и выходные 11:30–12:30 по местному времени, но данные аккаунта важнее общих советов.
- Не выкладывай несколько частей одновременно. Конец части: короткая карточка «ЧАСТЬ N · СКОРО», без «уже в профиле».
- Продолжения серий часто проваливаются: часть 1 получает охват, дальше просмотры падают. Делай каждую часть самостоятельной историей с собственным исходом.

## 6. Ловушки Windows
- Bash из Git Bash, а Python и Node Windows-овые: пути `/tmp` недоступны. Складывай временные файлы в `%TEMP%` через `cygpath -w`.
- Не используй heredoc с `\U` и кавычками для Python-правок сложных файлов: правь через Edit или пиши скрипт файлом.
- Параллельные рендеры не запускай. Чтобы остановить рендер, находи процесс `tools/render.mjs` по командной строке, не убивай все `node.exe`.
- Рендер выходит за 29 МБ: рендерщик сам повышает CRF, но не режь длительность без согласования.

## 7. Тон общения с владельцем
Коротко, по делу, с цифрами. Признавать ошибки прямо. Не предлагать лишнего, не переспрашивать то, что уже решено. Сначала правка, потом краткий отчёт «что исправил / что осталось».

## 8. Заметки по озвучке из практики
- Теги `[firm]`, `[grave]`, `[low, quiet voice]` на клонированном голосе (PVC) иногда дают глухой или шипящий звук, «как через плохой микрофон». Для строк-правил лучше писать без тегов, стабильность около 0,5.
- Проверка без прослушивания: спектр файла через ffmpeg + numpy (доля энергии выше 6 кГц, 99%-й срез). Это лишь подсказка, слова влияют на спектр, окончательно решает слух.
- Если у ElevenLabs бесплатный аккаунт: библиотечные голоса недоступны через API, только на сайте; следи за остатком символов.
